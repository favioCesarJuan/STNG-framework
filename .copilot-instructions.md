# 🛸 STNG-Framework GitHub Copilot Instructions

When generating code or proposing changes in this repository:
1. Adhere to **YAGNI** and **Ponytail Minimalism**: avoid adding third-party dependencies when native language primitives suffice.
2. Never introduce continuous polling with `setInterval` to sync client data. Rely on event-driven streams or focus revalidation.
3. Write clean unit tests using Node.js native test runner (`node:test`) or Vitest for business domain calculations.
4. Use CSS Modules (`*.module.css`) for web styles and `StyleSheet.create` for React Native.
5. Use `pnpm` as the preferred package manager for scripts and command lines.
